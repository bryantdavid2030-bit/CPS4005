# Store marketing assets

Generated by `yarn brand:assets` (runs `scripts/generate-brand-assets.mjs`)
from the canonical SVG sources in `assets/_sources/`. Commit the regenerated
PNGs before submitting to either store.

| File                          | Used by                 | Size       |
|-------------------------------|-------------------------|------------|
| `feature-graphic.png`         | Google Play listing     | 1024×500   |
| `../icons/icon.png`           | iOS app icon            | 1024×1024  |
| `../icons/adaptive-icon.png`  | Android adaptive icon   | 1024×1024  |
| `../splash/splash.png`        | iOS / universal splash  | 1284×2778  |
| `../splash/splash-android.png`| Android 12+ splash      | 1080×1920  |

Screenshot bundles live in `store/screenshots/` and are generated by
Fastlane — see `fastlane/Snapfile` and `fastlane/Screengrabfile`.
