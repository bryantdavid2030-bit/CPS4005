# Store screenshots

All screenshots are generated by Fastlane `snapshot` (iOS) and
`screengrab` (Android) running UI tests on a device matrix. See
`fastlane/Snapfile` and `fastlane/Screengrabfile`.

Required sizes:

## Apple App Store (per locale)
- 6.7" iPhone (1290 x 2796) — e.g. iPhone 15 Pro Max
- 6.5" iPhone (1284 x 2778) — e.g. iPhone 14 Plus
- 6.1" iPhone (1179 x 2556) — e.g. iPhone 15 / 15 Pro
- 5.5" iPhone (1242 x 2208) — e.g. iPhone 8 Plus

Minimum 3 screenshots, maximum 10. Recommended: 5 hero screens.

## Google Play (per locale)
- Phone: 1080 x 1920 (minimum 2, up to 8)
- 7-inch tablet: 1200 x 1920
- 10-inch tablet: 1600 x 2560
- Feature graphic: 1024 x 500 (required)

Hero screens (scripted in `scripts/screenshots.ts`):
1. Splash / logo
2. Home hero — "Human performance. On request."
3. Roster with filters
4. Coach detail
5. Enquiry form

Run locally:

```bash
# iOS
yarn prebuild
bundle exec fastlane ios screenshots

# Android
bundle exec fastlane android screenshots
```
